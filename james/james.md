# Jam3$-01

James is a small cross-platform terminal menu for local Ollama tools. Run it
with:

```text
python james.py
```

Its configuration is in `james/james.json`. It contains the active language,
chat model, database location, and flow lists for each category.

The main menu provides Chat, Flow, Database, Setup, About, Help, and prepared
MCP, RAG, and Cowork sections. Detailed controls are in `james/james_help.md`.
