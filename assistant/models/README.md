# Model reference

This directory contains locally recorded `ollama show` details for the models used or evaluated by this project.

- [qwen3.5:latest](qwen35.md) — general-purpose model with vision, tools, and thinking capabilities.
- [translategemma:12b](translategemma.md) — translation-focused Gemma model with vision support.
- [medgemma:latest](medgemma.md) — healthcare-oriented Gemma model with vision support.
- [gpt-oss:latest](gpt-oss.md) — general-purpose model with tools and thinking capabilities.
- [deepseek-ocr:3b](deepseek-ocr.md) — vision model focused on optical character recognition.

The linked files record the model metadata available at the date stated in each file.
