# Tato ukázka pouze čte už naplněnou gardening DB. Naplnění zdrojů je ve
# flow_rag_ingest_gardening.txt a spouští se jen po změně rag_wiki/src/gardening.

python cli_vector.py --db gardening search "rajčata" --mode text -k 5

# Hrubé propojení RAG -> existujícího kontextu pro Ollamu.
# Výstup z context není databáze: je to jen aktuální výběr pasáží pro jeden dotaz.
python cli_tool.py --clr
python cli_tool.py --add "RAG: gardening (rajčata)" wiki_gardening_context.txt
python cli_ollama.py --type task_base.json --sc-cz --input "Zadej otázku o rajčatech" - --rules "Odpovídej pouze podle dodaného RAG kontextu. Když tam odpověď není, otevřeně to řekni. Uveď použitý zdroj v hranatých závorkách." --context "RAG: gardening" tools_context.txt --out gardening_answer.txt

Pokud v něm není žádný zdrojový chunk k otázce, odpověz přesně: Ve wiki jsem pro tento dotaz nenašel podklady.
